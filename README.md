# DateTable

DateTable is a small desktop scheduler built with Python and PyQt5. You add events with a title, a description, a time and a date, and the app sends a desktop notification with a sound when an event's time arrives.

## Features

- Up to 6 events at a time, each shown as a card on the main window
- Each card shows the title, description, time, date, days remaining and a live countdown for events due today
- Add, edit, delete and activate/deactivate events
- Input validation for every field (hour 00-23, minute and second 00-59, valid day for the month, year within the next 50 years)
- Desktop notifications with sound, using `notify-py`
- Events are stored locally in a SQLite database (`Schedule.db`), so they survive restarts
- Frameless, draggable windows with animated menus
- Settings window with app info and a short help guide

## Requirements

- Python 3.9
- The packages listed in `requrments.txt`:
  - `PyQt5==5.15.4`
  - `pyqt5-tools==5.15.4.3.2`
  - `notify-py==0.3.3`

The app was built and tested on Windows. Icon and sound paths use Windows-style separators (`photo\logo.png`), so icons and the notification sound may not load on macOS or Linux without changing those paths.

## Installation

```bash
git clone https://github.com/sjdfani/DateTable.git
cd DateTable
pip install -r requrments.txt
```

## Running

Run the app from the repository root, so that the `photo` directory is next to your working directory. The app loads its icons and the notification sound from `photo`.

```bash
python Source/main.py
```

On first run the app creates `Schedule.db` in the current working directory.

## How to use

1. Click the menu button to open the toolbar.
2. Click **Add** and fill in the title, description, time (hour, minute, second) and date (year, month, day), then submit. The Add button is disabled once 6 events exist.
3. Click **Refresh** to load your events onto the main window.
4. Make sure the event's **Active** button is green. Events whose date has passed are deactivated automatically.
5. Click **Process** to start watching today's active events. The Process button turns green while it is running, and you get a notification when each event's time is reached. After it fires, the event is deactivated.

Use the **Edit** and **Delete** buttons on each card to change or remove an event.
